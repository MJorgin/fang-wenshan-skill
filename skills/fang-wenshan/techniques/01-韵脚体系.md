# 01 · 韵脚体系

方文山把韵脚当作歌词的骨架而非装饰。他自述创作始终围绕「情感最大公约数、人称代词、工整韵脚」三个核心，韵脚被并列为核心三要素之一（据烟台日报/中新网访谈，见来源 1）。

## 「素颜韵脚诗」——他自创的概念

「素颜」指一张素面朝天的纯粹中文的脸：不使用标点符号、外国文字、阿拉伯数字、图像等「化妆品」；「韵脚」则要求**每一行均须押韵**，读来朗朗上口如同歌谣（中华读书报蔡骏文，来源 2）。他写的素颜韵脚诗《泼墨山水》全诗无标点，靠空格断句：「篆刻的城　落款在　梅雨时节 / 青石城外　一路泥泞的山水一笔凌空挥毫的泪 / 你是我泼墨画中　留白的离别 / 滚动条上　始终画不出的那个　谁」。方文山称「写诗在某种程度上倒像是在悟禅」，并说「诗是对具象人事物的一种抽象解译……游走于一切事物之间」（来源 2）。周杰伦评价他的诗与词的区别：「他的词像拍好的 MV，他的诗像没拍 MV 的音乐，想象空间更大」（来源 2）。

## 一韵到底与近韵通押（实例）

以可核对的引文按普通话拼音标注（非权威统计）：

- **《青花瓷》副歌一韵到底 -i**：「天青色等烟雨　而我在等你 / 炊烟袅袅升起　隔江千万里 / 在瓶底书汉隶仿前朝的飘逸 / 就当我　为遇见你伏笔」——末字「你、里、逸、笔」均收 -i（衣期/一七辙），闭口收束，贴合等待的含蓄（引文来源 3）。
- **《东风破》副歌近韵通押 -o/-ou/-uo**：「谁在用琵琶弹奏一曲东风破 / 岁月在墙上剥落看见小时候 / 犹记得那年我们都还很年幼 / 而如今琴声幽幽我的等候你没听过」——「破、候、幼、过」分属 -o/-ou/-uo，属靠介音与声调的近似通押而非严格同韵（引文来源 4）。
- **《发如雪》副歌近韵通押 -ei/-ie**：「你发如雪　凄美了离别……邀明月　让回忆皎洁　爱在月光下完美……我等待苍老了谁……刻永世爱你的碑」——「别、谁、美、泪、谁、碑」在 -ie/-ei/-ui 间游移（引文来源 5）。

可见他的「工整韵脚」不等于机械同韵，而是**以近韵通押保持听觉上的黏着**，严格同韵主要出现在副歌金句段（如《青花瓷》的 -i）。

## 韵脚如何服务情绪

- 闭口韵 -i/-u 收敛内敛，配等待、隐忍（《青花瓷》副歌）；开口韵与鼻音韵尾 -ang/-an 适合铺开与抒情（此为按普通话拼音的通用声乐常识，方文山未逐首自述，见「空白点」）。
- 换韵通常发生在主歌→副歌、或情感转场的节点，副歌重复处回归稳定韵脚以强化记忆点（本卡据上引引文观察，非方文山逐字规则）。

> 高频韵脚（-ang、-an、-ou、-ing）的**频次排名**须以《方文山"中国风"歌词的语言风格研究》（万方学位论文，来源 6）与台湾《方文山創作歌詞之音韻風格研究》（来源 7）全文数据为准，两文均付费/需馆藏，本卡未取得正文，故不臆造排名；上文仅给可从引文逐字核对的实例。

## 可操作的创作清单

1. 先定主韵，列出 5–10 个同韵可用字再动笔（对应「工整韵脚」核心）。
2. 副歌金句用**严格同韵**（参考《青花瓷》-i 一韵到底），主歌可用近韵通押保持自然。
3. 若中途换韵，把换韵点放在主歌转副歌或桥段，副歌重复处回归主韵。
4. 情绪选韵：内敛/等待→闭口韵（-i、-u）；铺陈/开阔→开口韵与鼻音韵尾（-a、-ang、-an）。
5. 写完后用 `scripts/rhyme-check.py` 核对行末入韵率。
