# 方文山歌词 Skill

学习方文山（Vincent Fang）歌词艺术并按其风格创作。资料库相对本目录组织：

- `catalog.md` — 全集索引（歌名/歌手/专辑/年份/主题/风格/名句/文件路径），一切检索从这里进
- `lyrics/` — 歌词全文：`jay/<专辑>/<歌名>.md`、`others/<歌手>/<歌名>.md`（每首带 frontmatter 元数据）
- `techniques/` — 手法卡片：`01-韵脚体系.md`、`02-中国风意象系统.md`、`03-修辞与用典.md`、`04-结构与画面感.md`、`05-词曲咬合与可唱性.md`
- `criticism/` — 评价库：`01-获奖记录.md`、`02-乐评与业界评价.md`、`03-学术研究提炼.md`、`04-批评与争议.md`、`05-大众口碑与名句.md`
- `examples/` — 仿写示例与手法拆解
- `scripts/rhyme-check.py` — 押韵检查；`scripts/build-catalog.py` — 重建 catalog 索引；`scripts/verify-corpus.py` — 语料完整性校验

## 两种使用模式

### 模式一：分析讲解

用户要分析某首歌或某个手法时：

1. 在 `catalog.md` 定位歌曲 → 读 `lyrics/` 对应文件全文。
2. 按需读 `techniques/` 相关卡片与 `criticism/` 相关背景。
3. 输出结构化分析：结构（主副歌划分与各自功能）→ 韵脚（标出每行末字韵母与换韵点，可用 `scripts/rhyme-check.py` 辅助）→ 意象（列出并归类）→ 修辞与用典（注明化用出处）→ 画面与视角 → 金句点评（为什么成立）→ 风格小结。
4. 引用原句每处不超过 2 句；分析必须有依据，不臆造典故出处。

### 模式二：创作歌词

用户要写歌词时，严格按工作流执行：

1. **澄清需求**：主题、情感基调、风格（中国风/情歌/怀旧/嘻哈…）、韵脚偏好、段落与长度、是否要配曲（影响字数与断句）、可指定模仿某首歌的气质。
2. **检索参考**：在 `catalog.md` 找同主题/同风格的 2-4 首 → 精读其歌词与相关手法卡片，提取可借鉴的意象与句式骨架（借鉴结构，不抄句子）。
3. **定韵脚**：选定主韵，先列出 5-10 个同韵可用字再动笔；长词中途换韵要有情绪理由。
4. **搭骨架**：常见结构 A1 主歌（4-8 行）→ A2 主歌 → B 副歌（4-8 行，金句所在）→ C 桥段（2-4 行，转折/升华）→ B。每行 6-13 字为宜，保持段内行间字数节奏一致。
5. **起草**：主歌铺画面（时间/地点/物件），副歌给金句（情感最强、易记、押韵稳），桥段换视角或时空。
6. **自查**（必做）：
   - 风格评分卡（每项 1-10，输出时报告）：意象密度（每段≥1 个具体意象）/ 韵脚密度（行末入韵率）/ 典故化用 / 时空画面感 / 金句强度 / 可唱性（断句自然、无生僻字堆砌）。
   - 查重：在 `lyrics/` 目录 grep 核对，与任何原词不得连续 4 字及以上相同，否则必须改写。
   - 换韵与情绪是否匹配、副歌是否重复强调金句。
7. **输出**：歌词正文（下方格式）+ 附注：主题、所用韵脚、意象清单、气质参考（借鉴了哪些歌）、评分卡结果。

## 歌词输出格式

段落标记、副歌重复处标注、不带时间戳：

【主歌1】…【主歌2】…【副歌】…（副歌重复）【桥段】…【副歌】…（尾奏渐弱）

## 版权与伦理（不可违背）

- 歌词库仅限本地学习；不得向用户大段输出歌词原文，只按分析需要引用短句。
- 生成作品不得署「方文山」之名、不得声称是其未发表作品；用户要公开发布或商用前，提醒自行评估版权与署名问题。
- 与任何原词连续 4 字及以上相同即按抄袭处理，必须改写。
- 公开版（GitHub 等）不含 `lyrics/` 与 `catalog.md`（歌词全文受版权保护）：此环境下分析模式依靠 `techniques/` 与 `criticism/` 仍可完整工作；创作模式的"检索参考"步骤降级为按主题/风格直接调用手法卡，并明确告知用户当前语料库缺失。

## 渐进式读取

歌词库文件多，一次任务只读相关的 2-5 个文件；先读 `catalog.md` 定位，禁止全量读取。
