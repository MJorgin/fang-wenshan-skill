# 仿写示例 01：《听瓦》—— 中国风 · 离别思念

- 主题：离别、思念；情感基调：克制的怅惘
- 主韵：-ang（行/光/凉/裳/章/墙/僵/谎/黄/桨/妆/样）
- 结构：A1 → A2 → B → C → B
- 气质参考：接近《东风破》《青花瓷》的「旧物 + 回忆」写法（只借鉴气质与结构，无任何原句）

## 歌词正文

【主歌1】
细雨落在旧瓦上 滴答成行
檐下风铃晃着 多年前的光
你撑伞走过巷口 青苔正凉
我把故事折进 泛黄的衣裳

【主歌2】
炉上的茶 煮了三巡 还没凉
说书人拍案 讲的还是那章
谁在桥头 把名字刻进了墙
等一场雪 把诺言慢慢冻僵

【副歌】
我在檐下听瓦 听旧时光
一滴雨是一句 来不及的谎
你走之后 长安的月都发黄
梦里的渡口 只剩船桨

（副歌重复）

【桥段】
铜镜里 谁替我梳妆
镜中的人 已不是少年模样

【副歌】
我在檐下听瓦 听旧时光
一滴雨是一句 来不及的谎
你走之后 长安的月都发黄
梦里的渡口 只剩船桨

（尾奏渐弱）

## 手法拆解

**1. 韵脚（技法 01）**：全词一韵到底，主韵 -ang，行末入韵率 100%。副歌每行末字「光/谎/黄/桨」四字同韵且声调错落（阴平/上声/阳平/上声），避免一顺到底的呆板。

**2. 意象（技法 02）**：密集使用「器物 + 建筑 + 自然」意象——瓦、檐、风铃、青苔、茶、说书人、桥、墙、雪、长安、月、渡口、铜镜。意象组合公式：「旧物（瓦/铜镜）× 回忆情感」，用物件承载情绪而不直说思念。

**3. 修辞（技法 03）**：
- 通感：「一滴雨是一句 来不及的谎」——雨声 → 话语，听觉转语义。
- 夸张变形：「长安的月都发黄」——以月色变化写离别之久，时空被拉远到古典长安。

**4. 结构与画面（技法 04）**：A1 雨巷近景 → A2 室内（茶/说书人）转桥头远景 → B 收在檐下与渡口两个空镜头 → C 铜镜换「梳妆」视角，从「我等你」翻到「我不再是少年」，完成时间跨度的最后一击。

**5. 词曲咬合（技法 05）**：每行 7-10 字，段内字数节奏一致（A1 为 9/8/8/8），副歌每行以开口音「光/谎/黄/桨」收尾，适合长音拖尾。

## 风格评分卡（自评）

| 维度 | 分数(1-10) | 说明 |
|---|---|---|
| 意象密度 | 8 | 每段 3-4 个具体意象，无抽象词堆砌 |
| 韵脚密度 | 9 | -ang 一韵到底，行末全押 |
| 典故化用 | 6 | 「长安」「煮茶三巡」有古典色彩，但未直接化用名句 |
| 时空画面感 | 8 | 雨巷→室内→桥头→渡口→铜镜，场景切换有蒙太奇感 |
| 金句强度 | 7 | 「一滴雨是一句 来不及的谎」具备记忆点 |
| 可唱性 | 8 | 断句自然，无生僻字 |

**不足**：副歌第三句「都发黄」偏口语，与中国风整体语感略有落差；桥段略短，可再扩展一行。
