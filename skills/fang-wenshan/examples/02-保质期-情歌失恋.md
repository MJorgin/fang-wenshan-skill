# 仿写示例 02：《保质期》—— 情歌 · 失恋

- 主题：失恋、回忆；情感基调：自我安慰式的心酸
- 主韵：-ai（态/开/外/败/排/彩/袋/带/台/载/待）
- 结构：A1 → A2 → B → C → B
- 气质参考：接近《倒带》《说好的幸福呢》的都市情歌写法（只借鉴气质与结构，无任何原句）

## 歌词正文

【主歌1】
闹钟把昨天 调到静音状态
合照还在床头 你却已离开
手机里的对白 停在晚安之外
我练习微笑 好让自己不败

【主歌2】
冰箱里你买的 牛奶还没打开
过期的是我们 不是保质期那排
朋友问起近况 我都说很精彩
转身把雨伞 收进一个人的口袋

【副歌】
时间太快 故事怎么倒带
你的温柔 散落在每个站台
时间太快 回忆却不肯卸载
我在原地 等一个不会打烊的等待

【桥段】
这城市的雨 下得像比赛
输的人 要先学会把眼泪擦干再释怀

（副歌重复）

## 手法拆解

**1. 韵脚（技法 01）**：一韵到底 -ai，行末入韵率 100%。「态/开/外/败」是去声收束，副歌「带/台/载/待」同样去声，整首声调压得稳而沉，贴合失恋情绪。

**2. 意象（技法 02）**：都市器物意象——闹钟、合照、手机对白、冰箱牛奶、雨伞、站台、雨。用「过期牛奶」承载感情过期，是方文山式「用物件说话」的典型写法。

**3. 修辞（技法 03）**：
- 双关：「过期的是我们 不是保质期那排」——保质期既指牛奶又指感情。
- 拟人：「回忆却不肯卸载」——把记忆比作顽固的程序。

**4. 结构与画面（技法 04）**：A1 卧室近景（闹钟/合照/手机）→ A2 厨房与社交场景（冰箱/朋友问询）→ B 情绪总爆发（站台/原地等待）→ C 城市雨景收束。场景由内向外、由静到动，最后回到一个人撑伞的远景。

**5. 词曲咬合（技法 05）**：每行 7-10 字，A 段节奏 5+5 或 6+4 断句，副歌 4+6 断句（「时间太快 / 故事怎么倒带」），适合中速抒情曲；末字 -ai 均为开口收尾，适合拖音。
